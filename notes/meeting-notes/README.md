# Meeting Notes

This directory contains notes from meetings, calls, and discussions.

## Naming Convention

Use format: `YYYY-MM-DD-meeting-topic.md`

Example: `2025-10-24-team-standup.md`

## Template

```markdown
# Meeting: [Topic]

**Date:** YYYY-MM-DD  
**Time:** HH:MM  
**Attendees:** Name1, Name2, Name3

## Agenda
1. Item 1
2. Item 2

## Discussion Notes

### Topic 1

### Topic 2

## Decisions Made
- Decision 1
- Decision 2

## Action Items
- [ ] Person: Task description (Due: YYYY-MM-DD)
- [ ] Person: Task description (Due: YYYY-MM-DD)

## Follow-up
- Next meeting date
- Items to revisit
```
