# Daily Notes

This directory contains daily notes and journal entries.

## Naming Convention

Use the format: `YYYY-MM-DD.md`

Example: `2025-10-24.md`

## Template

```markdown
# Daily Note - YYYY-MM-DD

## 🎯 Goals for Today
- Goal 1
- Goal 2

## 📝 Notes

### Morning

### Afternoon

### Evening

## ✅ Completed
- Task 1
- Task 2

## 💡 Ideas & Insights

## 📌 Carry Forward to Tomorrow
- Item 1
```
