# Project Notes

This directory contains notes related to specific projects.

## Organization

Create a separate subdirectory for each project, or use files named after the project.

Example structure:
```
projects/
  project-name/
    overview.md
    tasks.md
    decisions.md
  another-project.md
```

## What to Include
- Project goals and objectives
- Technical decisions and rationale
- Meeting notes
- Progress tracking
- Resources and references
