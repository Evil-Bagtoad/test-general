# Learning Notes

This directory contains notes from courses, books, tutorials, and other learning resources.

## Organization

Organize by topic, course, or book:
```
learning/
  programming/
    python-advanced.md
    web-development.md
  books/
    book-title.md
  courses/
    course-name.md
```

## What to Include
- Key concepts and takeaways
- Code examples
- Exercises and practice notes
- Questions and areas to explore further
- Resources and references
